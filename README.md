# Learn Data Analytics 📊

This repository documents my complete learning journey toward becoming a **Data Analyst**.
It contains daily practice files, notes, exercises, and mini-projects created while learning
data analytics tools step by step.

The focus of this repository is **consistency, strong fundamentals, and practical learning**.

---

## 🎯 Goals of This Repository

- Build a strong foundation in Data Analytics
- Practice real-world data analysis techniques
- Learn how to clean, analyze, and visualize data
- Maintain daily GitHub activity as proof of consistency
- Prepare for entry-level Data Analyst roles

---

## 🛠️ Tools & Technologies Covered

- **Microsoft Excel**
  - Formulas
  - Data cleaning
  - Pivot tables
  - Dashboards

- **SQL**
  - Basic to advanced queries
  - Joins and subqueries
  - Data aggregation

- **Python**
  - Python fundamentals
  - Pandas & NumPy
  - Exploratory Data Analysis (EDA)
  - Data visualization

- **Power BI**
  - Data modeling
  - KPI dashboards
  - Business reports

## 📘 Learning Methodology

- Push updates to GitHub **daily**
- Write short notes after each study session
- Focus on understanding rather than memorizing
