# Learn Data Analytics 📊

This repository is a dedicated space for my journey into the world of Data Analytics. I am documenting my progress, hosting my practice scripts, and building a portfolio of projects using the "Core Four" tools.

---

## 🚀 The Roadmap
My goal is to master the full data pipeline: from data cleaning and querying to visualization and statistical analysis.

### 🛠 Tech Stack
* **Excel:** Data cleaning, Pivot Tables, and Lookup functions.
* **SQL:** Relational database management and complex querying.
* **Tableau:** Interactive data storytelling and dashboarding.
* **Python:** Data manipulation (Pandas) and Exploratory Data Analysis (EDA).

---

## 📂 Repository Structure

* 📁 **/Excel** - Spreadsheet models, dashboard files (.xlsx), and case studies.
* 📁 **/SQL** - SQL scripts (.sql), practice problems from platforms like LeetCode/HackerRank.
* 📁 **/Tableau** - Dashboard screenshots and links to [Tableau Public](https://public.tableau.com/).
* 📁 **/Python** - Jupyter Notebooks (.ipynb) and data cleaning scripts (.py).
