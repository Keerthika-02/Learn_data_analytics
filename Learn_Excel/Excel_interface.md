# Microsoft Excel – Basic Interface 

This guide explains the main parts of the **Excel window** (interface) that you see when you open Microsoft Excel (any recent version: 2016, 2019, 2021, 365).

## 1. Quick Access Toolbar
- Located at the **very top-left** corner
- Contains frequently used commands (can be customized)
- Default buttons usually include:
  - Save
  - Undo
  - Redo
  - New
  - Open
  - Quick Print

## 2. Title Bar
- Shows the **name of the current workbook** (e.g., Book1.xlsx)
- Also shows the **application name** → Microsoft Excel
- Contains the standard window controls:
  - Minimize
  - Maximize / Restore
  - Close

## 3. Ribbon
- The main command center – located below the Quick Access Toolbar
- Organized into **Tabs** (groups of related commands)

### Main Ribbon Tabs (most commonly used):
| Tab Name       | What you find there                              |
|----------------|--------------------------------------------------|
| **Home**       | Font, alignment, number format, copy/paste, cells |
| **Insert**     | Tables, pictures, charts, shapes, sparklines     |
| **Page Layout**| Themes, page setup, print area, gridlines        |
| **Formulas**   | Function library, formula auditing, calculation options |
| **Data**       | Get & Transform Data, sort, filter, data tools   |
| **Review**     | Proofing (spell check), comments, protect sheet  |
| **View**       | Zoom, freeze panes, gridlines, workbook views    |
| **Help**       | (sometimes) Access to help & feedback            |

- Each tab contains **Groups** (e.g., Clipboard, Font, Alignment...)
- Many groups have a small **Dialog Box Launcher** (tiny arrow) in the bottom-right corner

## 4. File Tab (Backstage View)
- Far left tab (green in some versions)
- Opens the **Backstage View** for:
  - New
  - Open
  - Save / Save As
  - Print
  - Share
  - Export
  - Options (settings)
  - Info (properties, protect workbook...)

## 5. Formula Bar
- Located **below the Ribbon**
- Shows the **contents** of the currently selected cell
- You can **edit formulas or text** directly here
- Has:
  - **Name Box** (left) → shows cell reference or named range
  - **fx** button → Insert Function wizard
  - Formula input area

## 6. Worksheet Area (The Grid)
- The main working area – made of:
  - **Columns** → labeled A, B, C, ..., Z, AA, AB... (vertical)
  - **Rows** → numbered 1, 2, 3, ... (horizontal)
  - **Cells** → intersection of column & row (e.g., A1, B5)

## 7. Sheet Tabs (Bottom)
- Located at the **bottom-left**
- Show names of worksheets (default: Sheet1, Sheet2, Sheet3)
- Buttons:
  - **+** → Insert new worksheet
  - **Scroll arrows** → move between many sheets
  - **Sheet navigation buttons**

## 8. Status Bar (Very Bottom)
- Shows useful information:
  - Ready / Edit / Enter mode
  - Average, Count, Sum of selected cells
  - Zoom slider
  - View buttons: Normal / Page Layout / Page Break Preview
  - Customize status bar (right-click)

## 9. Zoom Controls
- Bottom-right corner
- Zoom slider + percentage display
- Zoom in/out quickly

## 10. Tell Me / Search Box (sometimes visible)
- Top-right area (looks like a lightbulb or search icon)
- Type what you want to do → Excel suggests commands

## Quick Summary – From Top to Bottom

| Position       | Element                     |
|----------------|-----------------------------|
| Top            | Quick Access Toolbar        |
|                | Title Bar                   |
|                | Ribbon (Tabs & Commands)    |
| Below Ribbon   | Formula Bar + Name Box      |
| Main Area      | Worksheet Grid (Cells)      |
| Bottom         | Sheet Tabs + Status Bar     |
| Bottom-right   | Zoom controls               |
